# data 目录说明

本目录存放项目中的全部数据资产，包括原始文献、解析后的文献文本、筛选后的 RAG 语料、向量索引、患者样例数据以及 RAG 问答输出。

推荐理解方式：

1. `articles/`：文献全文本身及其解析、chunk、筛选后的文本语料。
2. `registry/`：文献清单和筛选清单，主要记录“有哪些文献、每篇文献是否进入知识库”。
3. `index/`：已经向量化并可被检索器直接加载的最终索引。
4. `patients_info_datasets/`：医院提供的患者样例数据，用于后续患者特征整理与多模态建模分析。
5. `rag/`：RAG 问答、证据检索、提示词和评估输出。
6. `raw/`、`processed/`：早期预留目录，目前不是主流程目录，后续如继续使用应先重新规划。

当前 RAG 主流程的核心产物在 `index/`，不是 `articles/` 或 `registry/`。`articles/` 和 `registry/` 主要用于追溯、重建和质控。
